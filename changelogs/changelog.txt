Changelog - 21 November 2026
=============================

Modernisation of the Liffey Valley AC website (branch: visual-improvements).
All changes are local and uncommitted.

assets/css/lvac.css
-------------------- Full restyle around CSS variables for the club palette (blue #2F318D,
  yellow #FCD50D): Inter font with system-stack fallback, smooth scrolling,
  custom selection colour and focus-visible rings.
- Modern fixed body background (subtle gradient glows) replacing the old
  full-page blue gradient.
- Home-page CTA blocks (.join, .showresults, .winterleague, .trackseason)
  rewritten as modern rounded cards with hover lift; removed all
  -webkit-gradient / IE filter / inset-shadow legacy code.
- Content areas (.content) render as cards; carousel, maps, coach photos,
  social icons, news list rows, pagination, tables, footer and search
  inputs rounded and polished to match.
- New prefers-reduced-motion block for accessibility.
- Navbar: position relative + z-index 1030, margin-bottom 24px (gap between
  menu and content), CSS-only hover/focus dropdown for desktop so the
  Join Us menu works without Bootstrap JS (fixes dropdown not opening),
  and .dropdown-menu.show rule preserving Bootstrap click behaviour.
- Fixed mobile clipping: .container overflow-x hidden -> clip (with hidden
  fallback), so the expanded mobile menu/dropdowns are not clipped.
- Added Bootstrap 3 compatibility aliases (.img-responsive, .center-block)
  that did nothing since the Bootstrap 5 migration.
- Homepage News list styled (white titles, muted dates); 50th video and
  carousel images get rounded corners/shadows; carousel has a soft bottom
  gradient overlay; #carouselExampleIndicators margin-bottom 16px after
  removing the yellow bar under the carousel.
- Meet Us member profile tables restyled as cards via :has() selector that
  only matches td-only tables (race results tables excluded).

_layouts/base.html
------------------
- Added Inter font (Google Fonts) with preconnect, theme-color and
  auto-generated description meta tags.
- Leaflet CSS upgraded 0.7.3 -> 1.9.4.
- Ghost .glyphicon mail icon in footer replaced with an inline SVG envelope.
- Shop nav item removed.
- Halloween pumpkin include removed entirely.

index.html / training.html / _layouts/race.html
-----------------------------------------------
- Leaflet JS upgraded 0.7.3 -> 1.9.4; map tiles switched from insecure
  http://{s}.tile.osm.org (deprecated, blocked on HTTPS pages) to
  https://tile.openstreetmap.org; attribution link updated to https.

index.html
----------
- Removed the yellow .bar divider row under the carousel.

join-us.html
------------
- Dead Bootstrap 3 glyphicons in Quick Links replaced with inline SVGs;
  removed btn-block (Bootstrap 2/3 class) in favour of w-100; list-group
  items tidied (rounded-3, border-0).
- Ghost mail glyphicon replaced with inline SVG.

tombrennan5k.html
-----------------
- Full rebuild with page-scoped styles (previous embedded body/* rules
  leaked onto the whole site layout on this page).
- Fixed stray </div class="row content"> tag and invalid class attribute.
- FAQ converted to a native details/summary accordion (no JavaScript,
  keyboard accessible) with rotating chevron and hover states; first item
  (entries + register) open by default.
- Register button moved from inline mouseover handlers to a real CSS class
  matching the homepage CTA.
- Section headers as consistent yellow gradient bands; course map and
  bobble-hat images in rounded media cards; prefers-reduced-motion support.
- All copy, links and PENDING 2027 notes preserved; verified all three
  2027 images exist in assets/images/tbm2027/.

_config.yml
-----------
- halloween config block removed (along with
  _includes/halloween-pumpkin.html). The pumpkin SVG image is kept in
  assets/images in case it is wanted again.

Not changed
-----------
- Bootstrap stays at 5.1.3 (upgrade would require touching SRI hashes and
  navbar markup across all pages).
- Header banner positioning untouched; tombrennan5k_old*.html archives left
  as they are.

Second batch - 21 November 2026 (same day, after the first commit)
==================================================================

Dependencies removed
--------------------
- Dropped jQuery 1.11 and the blueimp gallery from base.html; both were
  loaded on every page but no longer used by any active page.
- Removed /assets/css/bootstrap-image-gallery.min.css link and the
  bootstrap-image-gallery custom_js reference in gallery/index.html.
- Rewrote assets/js/search.js and assets/js/results.js in vanilla JS
  (same behaviour: footer search submits to /search?query=..., results
  page builds the lunr 1.0 index over search.json).
- New assets/js/lightbox.js: standalone photo lightbox for album pages
  (prev/next, Esc/click to close, photo counter), wired via custom_js in
  _layouts/gallery.html; album photos no longer open in new tabs.

Dead tracking removed
---------------------
- Google Analytics Universal (UA-74269934-1, shut down in 2023) and the
  Facebook Pixel removed from the production blocks of base.html.
- Homepage embedded Facebook page plugin (iframe + SDK) replaced with a
  follow-us card linking to the Facebook page.

Bootstrap 5.3.9
---------------
- bootstrap upgraded 5.1.3 -> 5.3.9 (CSS + JS); separate Popper script
  replaced by bootstrap.bundle.min.js; SRI hashes computed from the CDN
  files.
- Table CSS overrides migrated to the 5.3 variable names
  (--bs-table-bg-type / --bs-table-hover-bg / --bs-table-color).
- navbar-light replaced by data-bs-theme="dark" (5.3 color modes).

Homepage
--------
- Left-column announcements restyled as cards (.announce-card); the two
  expired-season retrospectives moved out of the homepage: the track
  season wrap-up became a news post
  (_posts/2026-10-04-Track-Season-2026-Wrap-up.md), the winter league
  final and track season pointer texts were already covered by the news
  posts they linked to.
- Fixed a typo'd href (doubled quote) that was removed with that block.
- JSON-LD image URL updated to https and the current logo.

Layout and pages
----------------
- All remaining yellow .bar divider rows removed from active pages and
  layouts (16 files); .bar rule reduced to display:none (kept for old
  archive pages).
- New shared _includes/page-hero.html (banner image + yellow title band)
  applied to join-us, training and meet-us.
- Date chips (.date-chip) added to the news and race page layouts.
- Focus glow polish: consistent club-yellow focus rings for buttons, nav
  links, dropdown items, toggler, pagination, register button and footer
  search controls.
- Social preview cards: Open Graph + Twitter meta tags in base.html
  (title, description, canonical URL, club logo image).
- Icons: apple-touch-icon (180), icon-192 and icon-512 generated from
  LVAC_2024_logo.png into assets/icons/ and referenced in base.html.
- Print stylesheet added to lvac.css (white background, nav/footer/maps
  hidden, URLs printed after external links).
